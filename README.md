### 정원영 · Wonyoung Jung

연세대학교 건설환경공학과 4학년, 스마트인프라연구실 학부연구생 (2026.01 ~).
**모방학습으로 벽돌을 쌓는 로봇**을 연구한다. 로봇 분야의 성공률이 아니라 **건설 시공 기준(KCS 허용오차)** 으로 결과를 평가하는 것이 관심사다.

| 프로젝트 | 내용 |
|---|---|
| [masonry-inspection-il](https://github.com/wonyoungjacob/masonry-inspection-il) | KSARC 2026 포스터(제1저자). MuJoCo에서 ACT 정책에 검측 6단계를 붙여 3단 16장 벽 완성률 0 → 60 % (100벽), 단계별 기여를 leave-one-out 짝 비교로 측정 |
| [so101-sim](https://github.com/wonyoungjacob/so101-sim) | 연구실 실물 SO-101 셋업(카메라 3대 · ChArUco 캘리브레이션)을 옮긴 MuJoCo 정밀 배치 환경과 4정책(ACT · Diffusion · SmolVLA · π0.5) 비교 파이프라인 |

- **해 본 것**: MuJoCo 시뮬레이션 · LeRobot(ACT, Diffusion Policy) 학습/평가 · 실물 SO-101 텔레오퍼레이션 데이터 수집과 CVAT 라벨링(연구실 팀 프로젝트) · 실험 설계와 부트스트랩 짝 비교
- **기초 수준**: Fusion 360 · 3D 프린팅 (손목 카메라 마운트)
- **일하는 방식**: 컴퓨터 전공이 아니다. 코드는 AI 코딩 도구(Claude Code, Codex)로 구현하고, 연구 질문 · 실험 조건 사전 고정 · 실패 원인 분석 · 결과 검증은 직접 한다.
